# مونتانا | Montana — متجر الهواتف الذكية

**المرحلة الأولى نُفّذت:** كتالوج حقيقي للهواتف، تصميم RTL متجاوب، ومقارنة ومساعد اختيار، وسعر صرف مرجعي سوري حي. **الطلبات الحقيقية والدفع والإدارة لم تُفعّل بعد.**

## ما الذي يعمل الآن؟
- تصميم جديد للهواتف، شعارات ماركات ومكوّنات وأيقونات SVG موحّدة.
- ستة موديلات بمواصفات مأخوذة من مصادر الشركات وروابط صور مختلفة.
- مزامنة قراءة عامة للهواتف المنشورة من Supabase؛ مفاتيح الإدارة لا تُعرض للعميل.
- تفاصيل الأجهزة والمقارنة مع شرح الاستخدامات، دون درجات أداء مختلقة.
- مستشار يعتمد على أولويات الزائر، وينبّه صراحة إلى أن الميزانية غير قابلة للتحقق قبل نشر أسعار المتجر.
- شريط مرجعي لمصدر الدولار في دمشق، مع وضع الليرة الجديدة والقديمة (**100 قديمة = 1 جديدة**) وتاريخ البيانات.
- حفظ المفضلة على الجهاز، وملفات PWA الأساسية.

## البيع والسلامة
- لا توجد أسعار معتمدة أو طلبات فعلية أو دفع حقيقي الآن. لا نعرض الأسعار التقديرية القديمة التي كانت في أول Demo.
- إلى أن تُثبت أسعار المتجر وتُفعّل الإدارة الآمنة، تظهر عبارة «السعر عند الطلب».
- صور الهواتف مرجعية من مواقع المصدر، ويجب التحقق من حقوق الاستخدام التجاري أو استبدالها بصور مرخصة قبل الإطلاق النهائي.
- جميع جداول Supabase الجديدة مفعّل لها RLS. إعدادات التسعير خاصة، ولا يوجد مفتاح service_role أو بيانات زبائن في المستودع.
- Cloudflare Worker نُشر يدوياً لوجود خطأ في تثبيت ربط GitHub بـ Cloudflare Pages؛ التحديثات التالية على GitHub لا تصل آلياً حتى يُصلح الربط.
- APK الحالي غلاف WebView تجريبي، ولم يُعتمد كتطبيق إنتاجي.
