# Montana Tech — مونتانا تك

نسخة أولية لتجربة متجر هواتف ذكية عربي، مع **12 هاتفاً مثالياً ببيانات وأسعار وتقييمات غير موثقة**. ليست عروضاً تجارية حقيقية.

## تجربة الموقع

Cloudflare Workers demo: https://montana-tech-demo.montanatech21.workers.dev/

- الماركات والسحب والبحث والتصفية
- استكشاف الهاتف وتفاصيله التجريبية
- مقارنة هاتفين بدرجات تجريبية **غير مستندة إلى اختبارات مستقلة**
- مستشار هاتف حسب الميزانية والأولويات بقواعد محلية، لا خدمة AI مدفوعة
- إكسسوارات وسلة محلية للتجربة فقط
- PWA/Service Worker أساسي؛ التثبيت والعمل دون اتصال يحتاجان اختباراً على الأجهزة

**غير متاح بعد:** الطلبات الحقيقية، الدفع، قاعدة البيانات، مصادقة المدير، صلاحيات الإدارة، المخزون الحقيقي، الإشعارات والتوصيل والولاء. لا تدخل بيانات زبائن حقيقية في النسخة الحالية.

## Android APK (debug / experimental)

تمت إضافة مشروع Android Java بسيط داخل مجلد `android/`، يعرض موقع Cloudflare داخل WebView آمن نسبياً (HTTPS ومجال محدود؛ لا توجد JavaScript bridge). **ليس بعد تطبيقاً أصلياً كاملاً**.

لإنشاء APK تجريبي:
1. افتح GitHub → Actions → `Android APK — demo`.
2. اختر Run workflow، أو راقب بناء workflow من آخر push على main.
3. بعد نجاح البناء، افتح Artifacts، وحمّل `montana-tech-demo-debug-apk`.
4. الملف الناتج `android-debug.apk` موقّع بتوقيع Debug آلي، للتجربة فقط وليس للنشر التجاري.

**لم يُؤكَّد نجاح بناء APK أو تثبيته على هاتف بعد.** يحتاج الجهاز إنترنت للتشغيل الأول؛ دعم العمل دون اتصال ليس مضموناً حتى اختباره.

## قاعدة البيانات

حساب Supabase الجديد متصل، وتوجد مؤسسة باسم `mobile21`، لكنها لا تحتوي مشروعاً لهذا المتجر بعد. لا نستخدم أياً من قواعد البيانات القديمة. عند إنشاء قاعدة جديدة نطبق RLS على الجداول ونحمي بيانات العملاء وعناوينهم وهواتفهم ونختبر صلاحيات المدير والعميل، ونمنع الطلبات المكررة.

## شروط الأمان

- لا ترفع بيانات زبائن أو مفاتيح Supabase secret/service_role أو رموز Cloudflare أو ملفات توقيع APK إلى مستودع عام.
- كل سعر ومخزون يتم التحقق منه على الخادم قبل قبول أي طلب حقيقي.
- لا تعتمد على درجات المقارنة الحالية في نصائح شراء فعلية.
- لا تعد APK debug إصداراً إنتاجياً؛ مرحلة الإنتاج تتطلب توقيع إصدار محفوظاً بأمان، واختبارات على أجهزة Android.
