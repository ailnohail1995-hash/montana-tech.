# فونكورا — FONKORA

متجر ومقارن عربي للهواتف الذكية، واجهته متجاوبة ومتصل بقاعدة Supabase مستقلة.

**النسخة الحالية للعرض والتقييم فقط. لم تُفعَّل عمليات البيع أو الدفع أو الطلبات حتى اعتماد الأسعار والمخزون والصلاحيات.**

## روابط التطبيق

- **الرابط الجديد باسم العلامة:** https://fonkora-store.montanatech21.workers.dev/
- الرابط القديم الذي بقي متاحاً للتوافق مع روابط ونسخ APK السابقة: https://montana-tech-demo.montanatech21.workers.dev/
- مشروع Supabase: https://supabase.com/dashboard/project/wxdspknjbbnarqnhptdx
- المستودع الحالي: https://github.com/ailnohail1995-hash/montana-tech. (اسمه التقني لم يتغير؛ ينتهي بنقطة)

## الوضع الحالي — 20 تشرين الثاني 2026

- **٣٠ هاتفاً منشوراً** بصور مميزة مُحسّنة، و**٢٦ مسودة** تحتاج استكمال التحقق من الصور وبيانات المنتجات.
- **٥٦ سعراً أولياً استرشادياً بالدولار** أُدخلت في جدول منفصل `public.phone_price_guides`، بينها ٣٠ سعراً متاحاً للقراءة العامة. هذه **افتراضات أولية للتجربة**، **ليست أسعار بيع أو أسعار سوق موثقة**.
- لكل هاتف منشور سعر استرشادي بالدولار وتحويل آني إلى الليرة السورية **الجديدة والقديمة**، مع اختيار العملة من أعلى الموقع: USD / ليرة جديدة / ليرة قديمة.
- سعر السوق المرجعي لدمشق يأتي من LiraScope API عبر Cloudflare Worker، مع المصدر ووقت التحديث؛ عند فشل مصدر دمشق قد يظهر **مرجع دولي** موصوف بوضوح. القيمة التقديرية ليست سعراً نهائياً للشراء.
- **١ ليرة سورية جديدة = ١٠٠ ليرة سورية قديمة**، وهو الفرق الذي تراعيه محولات السعر والميزانية.
- الهواتف، تفاصيلها، المقارنات، البحث، الفلاتر، المستشار، والمفضلة تعمل على الموقع.
- خدمة الصور الموجودة في Cloudflare محفوظة؛ لم تُغيّر صور الأجهزة ولم تُحذف بيانات أي مشروع آخر.

## سلامة السعر والبيع

`phone_price_guides` **جدول قراءته عامة للهواتف المنشورة فقط، وكتابته غير متاحة للزوار** بفضل GRANT + RLS. جميع القيم `is_approved=false`. ولا تُنشأ من هذه الأسعار أي سجلات `phone_variants` معروضة للبيع أو مدّعى أنها في المخزون.

سعر الصرف المعروض **مرجعي**، والاتفاق النهائي على السعر يتم عند تأكيد المتجر، بعد بناء إدارة موثوقة تتيح لصاحب المتجر اعتماد سعر كل إصدار/لون/سعة، ومراجعة المخزون وحفظ سجل التعديلات.

## البناء والاختبارات

- `node --check app.js && node --check stage2.js && node --check sw.js`
- `node tests/stage1.mjs && node tests/stage2.mjs && node tests/currency-prices.mjs`
- الفحص التفاعلي على عرض هاتف ٣٩٠ بكسلاً: ٣٠ بطاقة، ٣٠ سعراً أولياً، عملات ثلاث، تحويل بسعر API، تفاصيل الهاتف، وعدم وجود تمدد أفقي.
- GitHub Actions: `.github/workflows/web-check.yml`، وملف APK تجريبي عبر `.github/workflows/android-apk.yml`. **لا يوجد تأكيد بأن APK جديداً بُني أو جُرّب بعد تغيير الاسم.**

**النشر حالياً يدوي عبر Cloudflare Workers**؛ رفع ملفات GitHub وحده لا يعيد نشر الموقع تلقائياً، إلى أن يُصلح اتصال GitHub بـCloudflare.

## حقوق الصور والهوية

الصور المدمجة مأخوذة من مصادر أجهزة حقيقية؛ يجب التحقق من تراخيص إعادة استخدامها تجارياً. كذلك بحث اسم FONKORA كان بحثاً أولياً على الإنترنت، **ولا يثبت خلوه من حقوق علامات تجارية مسجلة أو توافر النطاق**.
