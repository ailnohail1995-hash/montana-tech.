# مونتانا تك | Montana Tech — Starter v0.1

**المرحلة المنجزة:** واجهة تجريبية عربية متجاوبة، من دون خدمات خلفية أو تعاملات تجارية حقيقية.

## التشغيل

- افتح `index.html` للتصفح العادي.
- لتفعيل تثبيت PWA والتخزين المؤقت، شغّل خادماً محلياً: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`، أو انشر على HTTPS في Cloudflare.
- البيانات والأسعار والمواصفات وترتيب الهواتف في `app.js` **تجريبية وغير موثقة، وليست عروض بيع**.
- المفضلة وسلة التجربة محفوظتان محلياً فقط. لا توجد مصادقة أو قاعدة بيانات، ولا يمكن استقبال طلبات حقيقية بعد.

## المنجز في نسخة البداية

1. صفحة اكتشاف وبحث فوري، ماركات بالسحب وفلاتر حسب الاستخدام.
2. بطاقات منتجات قابلة للاستكشاف ونافذة تفاصيل تفاعلية.
3. مقارنة هاتفين بنتائج مبنية على نقاط تجربة قابلة للتغيير (ليست مراجعات حقيقية).
4. مستشار اختيار غير قائم على نموذج AI: ميزانية + حتى 3 أولويات + ترتيب قابل للفهم.
5. قسم ملحقات وسلة محلية مع تعديل الكميات.
6. تخطيط معاينة للمدير، بدون أي صلاحيات حقيقية.
7. PWA manifest وservice worker لاستعراض الواجهة دون اتصال بعد زيارتها.
8. واجهة عربية RTL، أرقام شرقية عبر `Intl.NumberFormat`، وقوائم سهلة اللمس.

## ما لم يُنجز بعد (ضروري قبل البيع)

- مشروع Supabase **مستقل**، تصميم جدول `brands`, `phones`, `variants`, `accessories`, `compatibility`, `orders`, `order_items`, `customers`, `loyalty_ledger`, `offers`, `admin_roles` مع RLS واختبارات صلاحيات فعلية.
- الدخول الآمن للمدير، وإدارة المنتجات والطلبات والضمان والتوصيل.
- عرض صور وفيديوهات حقيقية من التخزين السحابي وتحسينها قبل الرفع؛ النموذج يستخدم رسومات CSS مؤقتة.
- مواصفات وأسعار ومخزون موثقة، تخزين التغيرات تاريخياً، والمقارنة وفق معايير موثوقة.
- خدمة تأكيد طلبات تتحقق من السعر والمخزون على الخادم، وتمنع التكرار وتخفي المعلومات الحساسة.
- إشعارات الدفع، واتساب، التقييم بعد الشراء، نقاط الولاء، التوصيل والعروض.
- اختبار PWA وملف APK بنظام TWA مع توقيع Android وسجل إعدادات التحديث.

## مقترح البنية الفعلية

Frontend: React + TypeScript + Vite. Hosting: Cloudflare Workers Static Assets. Database/Auth/Storage: Supabase. Android: Trusted Web Activity + Bubblewrap، مع دعم Android عند الحاجة لاحقاً عبر Capacitor. GitHub Actions معيارية للبناء على المستودع العام. الانتقال من هذه الواجهة الثابتة إلى واجهة React منظمة هو المرحلة المقبلة.

## أمان

**لا ترفع مفاتيح Supabase السرية أو service_role أو ملفات .env أو مفاتيح توقيع APK إلى مستودع عام.** بيانات العملاء الحقيقية تكون في جداول محمية مع RLS وتحقق من صلاحيات المسؤول. النشر العام للكود لا يعني النشر العام لبيانات العملاء.

## شروط قبل اعتماد الإنتاج

- تحديد حساب GitHub وCloudflare وSupabase المقصودة، وعدم مشاركة قاعدة بيانات مشاريع قائمة.
- اعتماد الاسم النهائي والهوية والألوان وطرق الدفع والشحن وحالات الطلب وسياسة الضمان.
- اختبار تنفيذ الطلب مرتين، والمزامنة عند انقطاع الإنترنت، وتغير الأسعار والمخزون أثناء الشراء.
